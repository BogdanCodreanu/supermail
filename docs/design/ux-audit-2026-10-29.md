# SuperMail UX audit — 2026-10-29

This is a code-level audit of `web/src` after day one (v0.1.3). The owner's verdict was "UX still needs a lot of work",
and they want it improved to a professional standard. Each item below names the file:line where the problem is,
followed by the fix.

## Quick wins

1. **Tab is hijacked.** `Inbox.tsx:218` binds Tab to "next group", and `useShortcuts.ts:37` swallows it, so keyboard
   users can't Tab to any control. Move "next group" to `]` and "previous group" to `[`, and leave Tab to the browser.
2. **No visible Compose or Search.** `Layout.tsx:6-10` has neither. Add a Compose button and a search field to the header.
3. **Back loses drafts.** The header Back (`Layout.tsx:19-23`), the NavLinks and browser back all skip the dirty check in
   `Compose.tsx:190-194`, and there is no `beforeunload`. Guard every exit.
4. **Nothing is selected on load.** `Inbox.tsx:90,100` leaves the selection null, so the first `e`, `h` or Enter does
   nothing. Select row 0 when the list loads and when the filter changes.
5. **The focused message in a thread is invisible.** `Thread.tsx:57` uses `bg-sel/40`, which doesn't compile for a bare
   `var(--sel)`. Use `bg-sel`, or define colors with `<alpha-value>`.
6. **Contrast fails.** `--faint` is 2.56:1 on light and 3.96:1 on dark, and it is used for dates, counts and hints in 14
   files. White on `bg-accent` in dark mode is 2.54:1 (Send, Connect, Reconnect).
7. **Thread actions give no feedback.** Done and snooze jump silently to the next thread; `+`, `-` and `u` show nothing;
   `z` works with no visible offer. Use UndoToast.
8. **Panel shows the wrong keys.** Settings and Search use the `list` context, so the panel shows j/k/e/h. Escape is
   unbound in Settings, Search and Skipped. Add `settings` and `search` contexts with Escape = back.
9. **Skipped differs from the inbox.** `Skipped.tsx:41-43` selects on click and needs a double-click to open, the cursor
   is the default arrow, undo is a separate banner without `z`, and the "i" hint is plain text.
10. **Search selection.** `Search.tsx:91-105` never scrolls the `j`/`k` selection into view, misuses `aria-current`, and
    formats dates differently from the inbox.
11. **Mixed icons.** The 📎 emoji (`ThreadRow.tsx:66`) sits beside text glyphs ← ▾ ✕ × ↓ ▲▼ and one SVG bell. Use one
    SVG set (lucide-react, 14–16px, `currentColor`).
12. **Group color picker.** `Settings.tsx:154` sends a PATCH on every drag step; commit on change or blur. The ▲▼
    reorder buttons (`:143-148`) are about 10px high; make them at least 24px.
13. **No focus styles.** There are no `focus-visible` styles, and inputs use `outline-none`. Add a global focus ring.
14. **Accessibility tail.**
    - Error toasts use `role="status"`; they should use `alert`.
    - Toasts don't pause on hover.
    - `ErrorLine` has no `role="alert"`.
    - `bg-red-50` and `bg-amber-100` have no dark variants.
    - `RequireAuth` renders a blank screen while loading.

## Larger changes

1. **The thread view has no visible actions.** `Thread.tsx:252-271` offers no Reply, Reply all, Forward, Done, Snooze,
   Unread or Always-group-to except by keyboard, which is a dead end for the mouse and blocks the phone layout. Add a
   sticky toolbar with labelled icon buttons and key hints, plus Reply and Forward under the last message.
2. **Back loses the inbox scroll and selection.** The inbox unmounts on `/t/:id`, so `selId` and the scroll offset are
   lost. Keep both in a store keyed by account and group.
3. **The iframe height is guessed.** `MessageBody.tsx:73-77` estimates it from text length and caps it at 900px, which
   causes nested scrollbars or gaps, and 600px+ newsletters scroll sideways. Fix: use sandbox `allow-same-origin`
   without `allow-scripts` (scripts still can't run), measure `scrollHeight` with a ResizeObserver, and scale wide
   content to fit.
4. **Replying hides the thread.** `/compose` replaces the thread view, so the quoted original isn't visible. Put an
   inline composer under the thread.
5. **Composer.**
   - Chips accept any string, with no validation and no autocomplete. Chips can't be edited, and Backspace deletes them
     silently.
   - There is no "Sent" confirmation and no undo send.
   - It uses `window.confirm`.
   - There is no draft autosave.
6. **Reading.**
   - Quoted text is never collapsed.
   - Collapsed previews are empty for HTML-only mail (`Thread.tsx:62`).
   - To and Cc are merged into one truncated line.
   - There are no full-date tooltips.
7. **Rows jump.** The selected row adds a reason line (`ThreadRow.tsx:89-105`), so the list shifts on every `j`/`k`.
8. **Rows aren't real controls.** `role="option"` rows contain buttons. There is no `aria-activedescendant`, and rows
   aren't links (no middle-click).
9. **Type scale.** Sizes run 10, 10.5, 11, 11.5, 12, 13, 13.5, 14 and 18px. Use 5 tokens (11/12/13/15/18) on a 4px
   spacing grid.
